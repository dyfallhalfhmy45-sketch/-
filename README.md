# 🥊 حرب الحارة

لعبة قتال كوميدية بستايل أركيد ١٦-بت تشتغل على المتصفح — بدون موسيقى، فقط أصوات ضربات، وتدعم الكمبيوتر والجوال والتابلت ويد التحكم.

**تطوير: ضيف الله الفهمي**

## المميزات
- **٢٦ مقاتل** (أبو الكبسة، الخطّاط، المشجع، الخالة أم المكنسة، الحراجي، الجد الزاحف، أبو الدركسون، الشقي أبو فتيل، المعلّمة، أبو الشاورما، أبو ضبّ، الكابتن مقلاع… وغيرهم)، ولكل واحد حركة خاصة و**ضربة سرية** 🤫
- أبو الشاورما إذا فاز يطلع له «تبي شاورمة؟» 🌯
- ١٠ ساحات: ليالي الدرعية، ضباب أبها، كورنيش جدة، البلد القديمة، رياض النيون، قاعة الوليمة، ملعب المدرسة، حظيرة الغنم، زقاق الفوانيس، كورنيش الغروب
- بعد كل مباراة (محلي أو أونلاين) تختار: جولة ثانية، أو قائمة الشخصيات، أو غيّر الساحة، أو القائمة الرئيسية
- **أونلاين برقم غرفة**: أنشئ غرفة وأعطِ خويّك الرقم (أو الرابط) وقاتلوا من أي مكان
- قتال ضد الكمبيوتر (٣ مستويات) أو لاعبين اثنين على نفس الجهاز
- **يد PlayStation / Xbox** (تنقّل بالقوائم + اهتزاز عند الضرب)
- **جري حقيقي**: تسارع تدريجي لسبرنت، ميلان وتمايل مع الخطوات، غبار، انزلاق عند الفرملة، وضربة اندفاع أقوى وانت تجري
- فيزياء ممتعة: تسارع واحتكاك، قفز مزدوج، اندفاع، تطيير وارتطام بالجدار، بحر شاي زلق، كاميرا تقرّب وتتبع الحركة وخطوط سرعة، اصطدام بين المقاتلين بزخم، سحق من الهوا (↓)، بطء عند الضربة القاضية
- أزرار لمس تلقائية على الجوال والتابلت
- أصوات الضربات مولّدة بالكود (بدون ملفات صوت وبدون موسيقى)

## 🕹️ قسم الأركيد
لعبتين، ولكل لعبة **تصنيف خاص بها**. قبل اللعب تكتب اسمك وتختار دولتك (كل دول العالم عدا إسرائيل وإيران)، ثم تختار المقاتل والساحة مثل اللعبة العادية.
- **💣 تفادي القنابل:** قنابل تسقط وتتدحرج، تفاداها (القفز والاندفاع يتفادى الانفجار)، اجمع الذهب لمضاعف ×٥، واضرب القنبلة عشان تطير بعيد. ٣ قلوب والنقاط = الوقت + الذهب + التفادي.
- **⚔️ موجات القتال:** خصم واحد، ثم اثنين، ثم ثلاثة… كل جولة يزيد العدد (وتزيد قوتهم). النقاط على كل خصم تهزمه واستكمال الجولات.
- التصنيف: تبويب **اللاعبين** وتبويب **الدول** (أفضل نتيجة لكل دولة). يتحدث بعد كل لعبة: اللي يجيب أعلى يرتفع.

### 🌍 تفعيل التصنيف العالمي (مرة وحدة)
بدون إعداد، التصنيف **محلي على نفس الجهاز**. عشان يكون عالمي لازم قاعدة بيانات:
1. ادخل [Firebase Console](https://console.firebase.google.com) وأنشئ مشروع مجاني، ثم **Build ← Realtime Database ← Create Database**.
2. في تبويب **Rules** الصق القواعد التالية واضغط Publish:
```json
{
  "rules": {
    "lb": {
      "$game": {
        ".read": true,
        ".indexOn": ["s"],
        "$key": {
          ".write": "($game == 'bomb' || $game == 'waves') && (!data.exists() || newData.child('s').val() > data.child('s').val())",
          ".validate": "newData.hasChildren(['n','c','s','t']) && newData.child('n').isString() && newData.child('n').val().length >= 1 && newData.child('n').val().length <= 16 && newData.child('c').isString() && newData.child('c').val().length == 2 && newData.child('c').val() != 'IL' && newData.child('c').val() != 'IR' && newData.child('s').isNumber() && newData.child('s').val() >= 0 && newData.child('s').val() <= 100000"
        }
      }
    }
  }
}
```
3. انسخ رابط القاعدة (يشبه `https://اسم-مشروعك-default-rtdb.firebaseio.com`) والصقه في `config.js` داخل `HW_LB_URL`.

> ⚠️ النتيجة تُرسل من متصفح اللاعب، فما نقدر نمنع التلاعب بالكامل. القواعد أعلاه تمنع تخفيض النتائج وتحدد سقف النقاط، ولحماية أقوى استخدم Cloud Functions أو App Check.

## التشغيل
افتح `index.html` مباشرة، أو:
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```
> اللعب الأونلاين يحتاج إنترنت (مكتبة PeerJS من CDN). يستخدم اتصال مباشر بين اللاعبين (WebRTC)، وفي بعض الشبكات قد لا ينجح الاتصال.

## النشر على GitHub Pages
1. ارفع كل الملفات في مستودع جديد.
2. **Settings ← Pages** ثم اختر `main` والمجلد `/ (root)`.
3. بعد دقيقة يطلع رابط اللعبة، وتقدر تشارك رابط الغرفة `?room=1234`.

## التحكم
| | لاعب ١ | لاعب ٢ | يد التحكم |
|---|---|---|---|
| حركة | A D | الأسهم | عصا / أسهم |
| قفز (مرتين بالهوا) | W | ↑ | A |
| صدّ | S | ↓ | LB |
| ضرب | F | K | X |
| خاصة (تحتاج ⚡) | G | L | Y |
| اندفاع | Shift أو ضغطتين على الاتجاه | ; | RB |

`Esc` / `Start` إيقاف مؤقت · `M` الصوت.

**الضربة السرية:** املأ شريط الطاقة كامل (★) ثم اصدّ وانت تضغط الخاصة.

## إضافة مقاتل جديد
1. جهّز sprite sheet بنفس الترتيب: وقوف، مشي، ضرب.
2. أضفه في `tools/slice_more.py` (جدول `CFG`) وشغّل `python3 tools/slice_sprites.py` ثم `python3 tools/slice_more.py` لتوليد `assets/chars/` و`assets/data.js`.
3. أضف مقاتل في مصفوفة `C` داخل `game.js` (واختر `sec` للضربة السرية في `secret()`).
